# Planilha-Financeira
Planilha financeira que ajuda a calcular investimento ao longo do tempo. 
Consegue verificar os valore apurados durante o tempo escolhido.
Ao clicar nos valore que deseja guardar, a planilha se ajusta e informa os novos valores.
Formulas ajudam a verificar os valores corretos, e aplicados
Se ajusta de acordo com o perfil do investidor. Claro que sempre pode ser melhorada, porém atende ao que foi solicitado.
